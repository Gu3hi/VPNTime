# VPNTime

轻点状态栏的时间，查看当前连接的 VPN 名称。

Tap the status bar clock to see the name of the currently connected VPN.

## 功能 / Features

- 轻点状态栏左上角的时间，时间淡出并显示当前 VPN 名称（如 Tailscale）
- 2.5 秒后自动淡出，恢复时间显示
- 无后台轮询，无日志，轻量无感
- Tap the clock on the top-left of the status bar — the time fades out and shows the current VPN name (e.g. Tailscale)
- Fades out after 2.5 seconds and restores the clock
- No background polling, no logs, lightweight

## 适用系统 / Compatibility

- iOS 17.0 及以上 / iOS 17.0+
- RootHide 越狱环境 / RootHide jailbreak
- 已在 iOS 17.3.1 + RootHide 上测试 / Tested on iOS 17.3.1 + RootHide

## 安装 / Installation

下载 Release 中的 .deb 安装包，通过包管理器安装后重新加载 SpringBoard 即可。

Download the .deb from Releases, install via your package manager, then respring.
